
# 🏎️ Desafio Pit Wall – GP de São Paulo

Projeto desenvolvido para a atividade de Linguagem de Marcação (LIMA), com o objetivo de recriar uma página inspirada no Grande Prêmio de Fórmula 1 de São Paulo, utilizando HTML e CSS.

## 🎯 Objetivo

Praticar os conhecimentos de HTML e CSS aprendidos no curso Sistema Musical, criando uma página responsiva inspirada no universo da Fórmula 1.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts (Titillium Web)
- Flexbox
- CSS Grid
- Media Queries

## 📂 Estrutura do projeto

```text
pit-wall/
│
├── index.html
├── styles.css
│
└── img/
    └── piloto.jpg
```

## 🏁 Funcionalidades e recursos

- Cabeçalho com logo e menu de navegação.
- Banner principal do GP de São Paulo.
- Imagem de fundo de um carro de Fórmula 1.
- Faixa decorativa inspirada na zebra da pista.
- Cards de pilotos com cores das equipes.
- Classificação dos pilotos em uma tabela.
- Área de ingressos com formulário.
- Efeitos de hover nos elementos.
- Layout responsivo para computadores e celulares.

## 🎨 Conceitos de CSS praticados

- `:root` e variáveis CSS.
- `display: flex`.
- `justify-content` e `align-items`.
- `display: grid`.
- `repeat(auto-fit, minmax())`.
- `form-grid`.
- `border`, `padding` e `margin`.
- `linear-gradient()`.
- `repeating-linear-gradient()`.
- `opacity`.
- `transition` e `transform`.
- `@media` para responsividade.

## 📱 Responsividade

O projeto utiliza Media Queries para adaptar a página a diferentes tamanhos de tela, proporcionando uma melhor visualização em computadores, tablets e celulares.

## 🚀 Como executar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta `pit-wall` no Visual Studio Code.
3. Confira se a imagem `piloto.jpg` está dentro da pasta `img`.
4. Abra o arquivo `index.html` no navegador.
